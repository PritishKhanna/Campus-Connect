# Campus Connect — Evaluation-I

## Goal
A polished but intentionally small static student opportunity portal for Front End Engineering-II Evaluation-I.

## Technology
- HTML5 semantic tags and accessibility basics
- CSS3 Box Model, Flexbox, Grid
- Responsive/mobile-first design and media queries
- JavaScript variables, functions, arrays, objects, loops
- ES6: let/const, arrow functions, destructuring, spread
- DOM manipulation and event handling
- JSON + Fetch API + async/await
- Forms + browser localStorage
- Git/GitHub ready folder structure
- NO React in Evaluation-I

## Files
- `index.html` — main landing page
- `login.html` — login UI and demo login interaction
- `style.css` — responsive styling and animations
- `script.js` — main JavaScript
- `opportunities.json` — opportunity data

## Run
Open the folder in VS Code and use Live Server. This is recommended because Fetch loads `opportunities.json`.
